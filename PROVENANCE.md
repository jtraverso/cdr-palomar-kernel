# Source provenance

The Lean source is copied byte for byte from the author's verified preparation
snapshot `ab700bdcfc988eccfcedc2f0e6bd0014189cda48`. No private Git history is
included. `docs/palomar/PACKAGE_AUDIT.json` records the source hashes.

The mathematical dependency sources are from the published shared archive,
SHA-256 `20bdbe78c88b2ebdd44daa7fe15355ce121430b0bd6e85e13951edc60472f5c9`.
Individual hashes are retained in `docs/palomar/local-snapshot/DEPENDENCY_SOURCES.json`.
Vendored projects retain their licenses and source attribution.

`LeanPool/Vizing.lean`, `LeanPool/Vizing/`, and
`LeanPool/ClassicalGraphColouring/Konig/Basic.lean` are the author's Lean Pool
contributions, under Apache-2.0; see `external/LeanPool-LICENSE` and
`external/LeanPool-Vizing.sha256`. The Kőnig source SHA-256 is
`d5377c49036d7293864765422017c615ba801a9bb958903a98eb5f7b1654a890`.

The original 49 off-diagonal tables are included in `data/archived_tables.json`.
Their source baseline is `76431935a1d61dbd7d512f32c941e37de38f6ba0`, archived
with the published preprints. Kernel certificates check the same entries;
the maximum order is 487. The original published freeze is unchanged.
